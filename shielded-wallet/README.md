# tesserax-shielded-wallet

Client of the shielded pool of [Tesserax](https://tesserax.app): shielded keys derived from an
account's seed, notes found by scanning the pool, synchronization of the note tree, and proven
transactions to shield, transfer privately and unshield TESS. It runs natively and in
WebAssembly.

Most applications use the `shielded` feature of
[`tesserax-sdk`](https://crates.io/crates/tesserax-sdk). See the
[documentation](https://docs.tesserax.app/privacy).
