# Tesserax documentation site

The site of https://docs.tesserax.app, built with Docusaurus from the Markdown of `../docs`: the
whitepaper, the lightpaper and the guides. The guides stay plain Markdown, readable on GitHub too;
links from them to files of the repository point to GitHub on the site.

```bash
npm install
npm start       # http://localhost:3000
npm run build   # build/
```

Built with this directory as root.
